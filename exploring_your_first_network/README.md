# Exploring Your First Network

Scripts Bash d'observation réseau sous Linux.

| Script | Rôle |
|---|---|
| `list_interfaces.sh` | Résumé des interfaces et de leurs adresses |
| `show_links.sh` | Informations de couche liaison (MAC, flags) |
| `test_loopback.sh` | Test ICMP de la pile locale |
| `show_default_route.sh` | Route IPv4 par défaut |
| `resolve_hostname.sh` | Résolution via la base hôtes du système |
| `show_neighbors.sh` | Table des voisins IPv4 |
| `list_listening_tcp.sh` | Sockets TCP en écoute |
